# 🍕 Domino's Pizza Data Analysis

## 📌 Project Overview

This project focuses on analyzing Domino's Pizza sales and customer data using **MySQL and Power BI**.

The goal of this project is to understand sales performance, order trends, customer behavior, pizza preferences, and revenue patterns through SQL analysis and interactive Power BI dashboards.

---

## 🎯 Project Objectives

* Analyze overall sales and order performance.
* Identify customer purchasing patterns.
* Analyze pizza categories and sizes.
* Identify top-performing pizzas.
* Understand daily, monthly, and hourly order trends.
* Analyze successful, cancelled, and failed orders.
* Segment customers based on their purchasing behavior.
* Build interactive Power BI dashboards for business insights.

---

## 🛠️ Tools & Technologies

* **MySQL** – Data cleaning, transformation, SQL analysis, and views
* **Power BI** – Interactive dashboards and data visualization
* **GitHub** – Project documentation and version control

---

## 🗄️ Database Structure

The project contains the following tables:

### 1. Customers

Contains customer information such as:

* Customer ID
* First Name
* Last Name
* Email
* Phone
* Address
* City
* State
* Postal Code

### 2. Orders

Contains order information such as:

* Order ID
* Order Date
* Order Time
* Customer ID
* Order Status

### 3. Order Details

Contains details of pizzas included in each order:

* Order Details ID
* Order ID
* Pizza ID
* Quantity

### 4. Pizzas

Contains pizza-level information:

* Pizza ID
* Pizza Type ID
* Size
* Price

### 5. Pizza Types

Contains pizza category and name information:

* Pizza Type ID
* Pizza Name
* Category
* Ingredients
